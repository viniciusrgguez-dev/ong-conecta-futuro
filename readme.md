# 🌐 ONG Conecta Futuro

Projeto desenvolvido como atividade prática do curso de Análise e Desenvolvimento de Sistemas. A aplicação é uma Single Page Application (SPA) responsiva e acessível para a ONG Conecta Futuro.

## 🚀 Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (com variáveis para tema escuro e alto contraste)
- JavaScript Vanilla (com manipulação de DOM e `localStorage`)
- Vite (ferramenta de build)
- Git & GitHub (versionamento)
- Vercel (deploy e hospedagem)

## ♿ Acessibilidade
O projeto segue as diretrizes da WCAG 2.1 AA, contando com suporte a leitores de tela, navegação via teclado, botões para ajuste de fonte e alternância de temas.

## 🛠️ Como rodar o projeto localmente
```bash
# Clone o repositório
git clone [https://github.com/viniciusrgguez-dev/ong-conecta-futuro.git](https://github.com/viniciusrgguez-dev/ong-conecta-futuro.git)

# Acesse a pasta do projeto
cd ong-conecta-futuro

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
npm run dev
